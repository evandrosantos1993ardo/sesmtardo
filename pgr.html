16+01 PGR - Plano de Ação | Transardo

⚙️ Configuração Inicial

Informe o ID da planilha Google Sheets que será usada como banco de dados do sistema PGR - Plano de Ação da Transportes Ardo Ltda.

Como preparar a planilha:
  1. Crie uma planilha no Google Sheets
  2. Renomeie a aba para plano_acao
  3. Na linha 1, adicione os cabeçalhos:
    ID | Atividade | Descricao | Setor | Cargo | Risco | Responsavel | Prioridade | Data_Inicio | Prazo_Final | Status | Observacoes | Data_Criacao | Ultima_Atualizacao
  4. Vá em Extensões → Apps Script, cole o script disponibilizado e publique como Web App (acesso: Qualquer pessoa)
  5. Copie a URL do Web App abaixo

O script Apps Script necessário está descrito na documentação do sistema.
