Configurar Integração com Google Sheets

🔗 Conectar com Google Sheets

Siga os passos abaixo para conectar o dashboard com sua planilha.

1
Crie uma planilha no Google Sheets com as colunas: ID, Titulo, Descricao, Responsavel, DataCriacao, Prazo, Status, UltimaAtualizacao
2
Abra o editor de scripts: Extensões → Apps Script
3
Cole o código do arquivo google-apps-script.gs no editor e salve
4
Faça o deploy: Implantar → Nova implantação → App da Web → Acesso: Qualquer pessoa
5
Copie a URL gerada e cole abaixo:
Nova Atividade
